🌾 KrishiConnect

KrishiConnect is a full-stack MERN application designed to connect farmers directly with buyers, removing middlemen and enabling fair pricing, transparency, and efficient trade in the agricultural market.

🚀 Overview

The platform provides a digital marketplace where farmers can list their products and buyers can purchase them seamlessly. It also offers real-time market insights and communication features to enhance decision-making and user experience.

✨ Key Features
🛒 Product Marketplace
Farmers can add, update, and manage their products while buyers can browse and purchase.
🔐 Authentication & Authorization
Secure user authentication using JWT.
📊 Market Analytics
Displays price trends, demand, supply, and market insights.
💬 Real-time Chat System
Enables direct communication between farmers and buyers using Socket.IO.
🔔 Notification System
Real-time alerts for orders, messages, and updates.
❤️ Wishlist Functionality
Users can save products for later.
🤖 AI-Based Insights
Provides smart recommendations based on market data.
